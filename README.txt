LUGHERI STORE - site editável
1. Abra index.html no navegador.
2. Use a seção "Editar produtos" para cadastrar nome, categoria, preço, tamanhos, cores, imagem e descrição.
3. Os produtos ficam salvos no navegador (localStorage).
4. Para publicar na internet, envie index.html e logo.jpg para um serviço de hospedagem de site estático.
5. O botão WhatsApp precisa do número da loja configurado no código.
